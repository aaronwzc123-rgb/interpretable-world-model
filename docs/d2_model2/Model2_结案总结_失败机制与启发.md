# Model 2（N-DNF Transition）结案总结：怎么失败的，留下了什么

> 状态：**正式收档，宣告失败**。GPU 与主线转向 Model 3 × 多环境（MemoryS7 等）。
> 口吻约定：【实锤】= 日志/数据直接支持；【推断】= 从实锤合理推出；【假设】= 待验证。

## 一、一句话结论

图 3 架构（N-DNF 取代 RSSM 作为转移函数、belief 本身是谓词）在三次公平机会后仍无法学会 DoorKey-6x6：**世界模型的 belief 没学会 9 个谓词中的 8 个（全部趴在 base rate 附近），导致想象通路奖励饥饿、actor 全程零学习信号**。失败被定位到**集成层**（首要嫌疑：KL 一致性正则把 posterior 拉向退化为噪声的 prior，压过接地监督），而非 N-DNF 电路本身的能力缺陷。

## 二、三次机会的时间线

| 轮次 | 做了什么 | 结果 | 结论 |
|---|---|---|---|
| 原版（ndnf_dreamer_demo_anneal_s0） | NDNFRSSM，300k 步 | eval ~0；BFS 热启动期 0.96、一停即崩 | 发现 delta_delay=1e9 配置 bug（300k 步内退火永不启动，delta 全程 0.1）+ delta 上限被硬编码 1.0 【实锤】 |
| deltafix 复训 | 只改 delta_delay=500 | 22% 处 env worker 崩溃；delta 已爬到 0.418，score 无变化 | 机制验证正确，但数据不足以判死 |
| 干净重建（m2rebuild） | 以 example 成功代码为底座，核心架构变量 = RSSM→NDNFTransition；三优化器 / delta 调度(0.1→4.0, 147.5k 步封顶) / 无热启动 / straight-through 梯度全部验证健康 | 早期 eval 0.10-0.13；~130k（delta 硬化）起单调下滑；182.5k 起 260 局评估零通关 | 基建健康 + 单变量 ⇒ 失败可干净归因到架构本身 【实锤】 |

**"再给几次机会"的账到此结清：** 一次是配置事故，一次中断，第三次是基建全绿的受控实验——失败是真实的、可复述的、带机制解释的。

## 三、失败机制的完整解剖（四次尸检链）

四次尸检全部零 GPU 成本（随机评估 / 读磁盘 / 加载 checkpoint 不训练），合计不到一小时，替代了可能数天的盲目重训。

### 尸检 1：随机基线 —— "学习信号"从来不存在
均匀随机策略同批测试：success 24%，mean return 0.0953。训练曲线里 0.10-0.13 那段与随机同量级。**actor 从头到尾没学过任何东西**；末期熵退火把一个没学过的策略确定化，反而收敛到错误行为（0.000，比随机还差）。【实锤】

### 尸检 2：逐谓词 acc vs base rate —— belief 只学会一个谓词
| 谓词 | base | acc | gain |
|---|---|---|---|
| wall_ahead | 0.578 | 0.942 | **+0.364** ✅ |
| t_ahead | 0.728 | 0.778 | +0.050（弱） |
| 其余 7 个（含 has_key/carrying/door_locked） | — | — | −0.08 ~ +0.01，其中 3 个低于瞎猜 |

这是在**密集 BCE 直接监督**（每步喂真值）下的失败——对架构最重的指控。早前"均值 0.78-0.80 = 表征健康"的说法是未对照 base rate 的误判，已纠正。【实锤】

### 尸检 3：actor 损失解剖 —— 饥饿是结果，不是独立病因
- imag_gradient='reinforce'，主项按设计不经过 dynamics ⇒ **排除"梯度穿不过硬化 prior"**。
- 想象窗口内 imag_reward≈0，advantage = 0.00036±0.00168（纯噪声）⇒ **奖励饥饿**。
- 但饥饿的根源不是 horizon（Model 3 同代码、同 horizon、同稀疏奖励训到 100%），而是 belief 连 has_key 都表示不了 ⇒ reward head 与想象展开无从预测奖励。**尸检 2 的病导致尸检 3 的症。**【实锤+推断】

### 尸检 4：当前帧 probe —— 任务前提本身破产
9 个谓词全部仅凭当前帧即可被线性 probe 判到 88-100%（has_key/carrying 100%：钥匙画在 agent 自格）。与 r2dreamer 侧 Model 1 的防作弊发现完全同构。两个后果：
1. **DoorKey（此 grid 编码）上任何人都不能主张"记忆"**——包括 Model 3；记忆主张必须去 MemoryS7。
2. 失败升级为更重的版本：N-DNF transition 连**线性 probe 都觉得毫无难度的可观测量**都没学好。【实锤】

### 最终归因：集成层假设（首要嫌疑：KL 拔河）【推断→尸检5裁决措辞】
"N-DNF 学不会监督信号"这一过强结论被否决——它与 pix2rule / neural-dnf-cub / DNF-MT 的已发表记录（导师及合作者本人的工作）直接冲突，且解释不了 wall_ahead 的选择性存活。更精确的机制假设：

> **posterior 输入含 tanh(prior_deter)，训练中 KL 一致性损失把 posterior 往 prior 拉；而 prior 是一条离散采样噪声链，其稳态即边际分布（= base rate）。于是 BCE 把 posterior 往真值拉、KL 把它往"噪声先验"拉——8 个谓词输掉了这场拔河，恰好一个（wall_ahead，静态几何、prior 也易预测、KL 阻力小）幸存。**

该假设一次性解释：base rate 扁平化、部分谓词低于 base rate、唯一幸存者。次级嫌疑：obs_proj 16 维瓶颈、循环噪声输入。三个嫌疑全在集成层，无一指向电路能力。
**尸检 5（静态离线拟合：同一 N-DNF 模块去循环、去 KL、纯 BCE）已布置**——它不改变任何决策，只裁决论文措辞在"电路无罪、集成致死"与"容量/实现问题"之间二选一。

### 被干净排除的假设清单
delta 调度（重建版全程正确，147.5k 封顶 4.0）；tanh 饱和梯度消失（硬化后 prior/post 梯度反而变大）；梯度穿不过硬化 prior（REINFORCE 不走 dynamics）；优化器/学习率（三优化器对齐成功版）；BFS 热启动缺失（成功版无热启动也训成）；"记忆太难"（任务根本不需要记忆）。【实锤】

## 四、对未来的启发

### 4.1 设计原则（论文级，三角互证）
三条实验线拼出一个中心论点：
- Model 2【本文】：**离散逻辑循环带不动跨时信息**（连可观测量都被循环噪声与 KL 拔河污染）；
- MemoryS7 shaping 实验：**连续 deter 通道恰恰擅长承载记忆**（纯记忆解码 0.81 vs 当前帧对照 0.53）；
- Model 3：**逻辑放在决策接口上因果有效**（原子清零 1.000→0.000）。

⇒ **"记忆需要连续基底，逻辑属于接口层"** —— 把每种表征放在它擅长的位置。Model 2 的负结果由此升格为该论点的必要一角，而非沉没成本。

### 4.2 一个可写进 discussion 的机制洞见【假设，尸检5后定稿】
Dreamer 的 KL 机制隐含假设 **prior 是有信息的**；当 prior 退化为噪声（离散采样链的稳态），同一个正则会**反噬表征学习**——把 posterior 拉向无信息分布，压过监督信号。对任何"把离散/符号模块嵌入世界模型循环"的后续工作，这是一条具体的避坑指引。

### 4.3 方法论教训（进《协作规范》候选）
1. **防作弊对照必须前置到环境选型日。** "DoorKey 需要记忆"这个前提从未被验证就开工了；一个几分钟的当前帧 probe 本可在数周前改变环境决策。新环境接入的第一件事：跑 grid probe 对照表。
2. **单变量纪律是归因能力的来源。** 干净重建（底座对齐成功版、唯一变量 transition）是本次能把失败钉到架构上的先决条件；此前旧版的失败因多变量纠缠而无法归因。
3. **零成本尸检先于 GPU。** 四次尸检 <1 小时，分辨了"随机 vs 学习""表征 vs 策略""记忆 vs 可观测"三组混淆——每一组若靠重训排查都是数天。
4. **负结果的价值取决于解剖深度。** "我们试了没成"不可发表；"belief 学不会可观测谓词 → 想象奖励饥饿 → actor 零信号，首要嫌疑 KL 拔河，同条件 RSSM 对照正常"是论文素材。
5. **警惕过强归因。** "X 学不会监督信号"这类结论要先过一遍已发表记录（尤其当 X 是导师的模型）；幸存者（wall_ahead）是归因方向的路标。
6. **配置卫生。** delta_delay=1e9 是手滑占位值；原 run 的 .hydra 快照被后续操作覆盖导致取证只能靠 metrics 反推。规矩：占位值当天清、logdir 不复用。
7. **热启动的隐性代价。** BFS 喂答案期的 0.96 是假象，且可能让策略学会"等答案"；成功版无热启动反而训成。

### 4.4 资源备忘（Kitty neural-dnf 2.0.0，2025-07）
- **Monitoring/自适应 delta 调度器**（= 导师组会提到的 adaptive delta）：对 Model 2 已不相关（delta 被排除），但若未来任何 N-DNF 训练再现"硬化窗口 = 性能崩塌"签名，这是对症的现成方案（移植门控机制、保留本项目 4.0 语义）。
- **Disentanglement 规则提取**（split_entangled_conjunction，NeSy 2025）：替代阈值化、减少提取损失。**与训练无关、零风险**，建议接入 Model 3 的 sym_rules() 流程——引用导师合作者最新工作，纯加分项。
